# 🚀 PromptForge Studio | AI Prompt Format & Enhancer Workbench

**PromptForge Studio** is a sleek, client-side web application designed to transform raw, unstructured user thoughts into high-performance, professional master prompts for Large Language Models (LLMs) like ChatGPT, Claude, and Gemini.

---

## ✨ Features

- **Persona & Role Customization:** Select from various expert roles (Senior Software Architect, Full-Stack Developer, Cybersecurity Specialist, etc.).
- **Tone & Style Controls:** Fine-tune outputs with specific communication tones (Professional, Concise, Step-by-Step).
- **Format Constraints:** Tailor the expected output layout (Markdown, Bullet Points, Implementation Guides).
- **Live Character Counter:** Real-time tracking of input length.
- **One-Click Copy:** Instant clipboard copy with animated toast notifications.
- **Dark Glassmorphic UI:** Modern cyberpunk-inspired dashboard aesthetic built with pure CSS.

---

## 🛠️ Tech Stack

- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, Grid, Custom CSS Variables, Glassmorphism)
- **Vanilla JavaScript (ES6+)** (DOM manipulation, Clipboard API)
- **FontAwesome** (Icons)

---

## 🚀 How to Run Locally

1. Clone or download this repository to your local machine.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension in VS Code.
4. Right-click on `index.html` and select **"Open with Live Server"**.
